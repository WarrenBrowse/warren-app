This directory contains the images for the menubar/traybar. The content consists of:
  * `svg/`: the frame sources, drawn from `graphics/logo-mark.svg` by
    `../../scripts/menubar-icon-frames.py`, and `notification.svg`, which only
    sets the colour of the notification dot. Never edit a `tray-*.svg` by hand.
  * png/ico files rendered from those sources. These should not be edited or
    replaced manually either.

## The icon
The tray icon is the Warren W. The inside of the W fills as the tunnel comes up:
empty when unsecured, a little under half when securing (traffic blocked, no
tunnel yet), full with a soft glow when secured. The state lives in the shape,
not only in the colour, so it survives the monochrome variants. The frames in
between are the fill rising, stepped evenly by filled area, and
`src/main/tray-icon-controller.ts` walks through them towards the target state.
The notification dot is drawn between the ears, inside the icon, so a
notification never changes the icon's width.

## Build script
Everything is regenerated by one script, run from the `desktop/packages/mullvad-vpn`
directory:
```sh
./scripts/generate-menubar-icons.sh
```

It writes the SVG frame sources, then renders each platform's tree twice: the
prod icons at the root, and a `beta/` subdirectory holding the same file names
with the icon drawn in another hue family. `src/main/tray-icon.ts` inserts that
segment for every non-prod product environment (beta and staging), so a machine
running two Warren installs never shows two identical tray icons.

The colour table, and why those hues, is
[`graphics/menubar-beta-palette.txt`](../../../../../../graphics/menubar-beta-palette.txt);
the generator refuses to write an icon in which a production colour survived,
and `test/unit/tray-icon-beta-palette.spec.ts` reads the pixels back. The
monochrome variants (macOS Template, Windows black and white, Linux white) hold
identical bytes in both trees: they are single-tint alpha masks with no colour
to move, so the distinction is lost for anyone who turns the monochromatic tray
icon on. `test/unit/tray-icon-frames.spec.ts` checks that the states stay
apart in those masks.

### Dependencies
Python 3, ImageMagick and librsvg (`rsvg-convert`).
